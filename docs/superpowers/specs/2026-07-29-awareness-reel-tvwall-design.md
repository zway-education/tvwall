將現有直式影片「01_覺知是什麼？為什麼這麼重要_正式版.mp4」重新排版為真正的 1920×1080 橫式版本，並加入目前線上正常版電視牆輪播。

- 來源影片：1080×1920、H.264、30fps、AAC、約 106.1 秒。
- 排版來源：原始 HTML 動畫、品牌字型、插圖與現有 21 幕內容。
- 輸出影片：1920×1080、H.264、30fps、`yuv420p`、AAC。
- 音訊：沿用正式版影片的既有音訊軌，不改音樂、語音或時間長度。
- 檔案大小：以智慧電視串流穩定為優先，目標不超過 80 MB，且不得超過 GitHub 單檔限制。

## 16:9 重新排版

不是將 9:16 影片置中加黑邊，也不是放大裁切。21 幕依內容分為五種橫式版型：

1. **封面與過橋**
   - 大標題置左，插圖或視覺線索置右。
   - 品牌標誌固定在安全區內。
   - 保留原本的標題進場與過橋節奏。

2. **六個家長痛點**
   - 左側為家長可快速讀懂的問題與關鍵詞。
   - 右側放對應插圖或情境畫面。
   - 同系列保持一致，但每頁依文字量調整比例，避免套同一模板後產生大片空白。

3. **覺知三步驟**
   - 使用橫向流程與清楚的先後關係。
   - 當頁重點放大，其他步驟降為輔助層級。

4. **三大系統**
   - 腦科學、管理學、正向心理學各自保有識別色與主要圖像。
   - 科學定位為精準輔助，不取代「用心理解孩子」的核心訊息。

5. **課程資訊與 CTA**
   - 課程資訊採左右雙欄或橫向卡片。
   - QR Code 保留完整白色 quiet zone，電視實際顯示邊長至少 300px。
   - 重要日期、時間與行動文字優先放大。

## 電視安全規則

- 所有重要文字與人物保持在 1920×1080 的 5% 安全區內。
- 不得出現黑色外框、上下黑邊、文字溢位、孤字或人物被裁切。
- 最小主要內文字級以 34px 為目標；補充資訊不得小於 28px。
- 中文依語意斷行，不把單一字留在下一行。
- 影片每一幀滿版 16:9，原始直式素材只作為內容來源，不直接縮小嵌入。

## 加入現有輪播

- 新增一個獨立的影片 scene，放在現有「課程核心」頁之後。
- 進入影片 scene 時，影片從 0 秒開始播放。
- 輪播停留時間以影片實際長度為準；播放結束後自動進入下一頁。
- 離開影片 scene 時停止並歸零，下一輪重新播放。
- 現有靜態頁仍維持原本的輪播時間、鍵盤切換與順序。
- 音訊先嘗試依影片原音播放；若智慧電視瀏覽器阻擋有聲自動播放，則自動退回靜音播放，確保輪播不中斷。檔案仍保留完整音訊軌。
